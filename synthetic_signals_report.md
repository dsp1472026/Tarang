## 2. Root Cause Analysis

### A. Why [hello_bpsk.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_bpsk.iq) Works Perfectly
1. **ASCII Binary Encoding**: [hello_bpsk.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_bpsk.iq) is the only signal created in [sg.py](file:///e:/SIH%2726%20-%20Restart/Test-Data/sg.py) by converting explicit ASCII bytes (`"HELLO WORLD"`) into binary antipodal phase states ($\pm 1$).
2. **Low Constant-Envelope PAPR**: BPSK has a constant envelope ($\text{PAPR} \approx 4.61\text{ dB}$ with RRC filter shaping).
3. **Unambiguous Boundaries**: Both the RadioML ONNX model and DSP cumulants ($|C_{40}| = 1.465 \ge 1.30$) classify it as **BPSK** with **97.4% confidence**, leading to **0% bit error rate**.

### B. Why [hello_16qam.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_16qam.iq) and [hello_64qam.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_64qam.iq) get Misclassified as `256QAM`
1. **Pulse Shaping Peak Inflation**: In [sg.py](file:///e:/SIH%2726%20-%20Restart/Test-Data/sg.py), 16QAM and 64QAM signals are generated using RRC filter convolution ($\text{span}=10, \text{sps}=8$). Inter-symbol transitions create transient peak overshoots, driving raw PAPR to:
   * **16QAM**: $\text{PAPR} = 5.41\text{ dB}$
   * **64QAM**: $\text{PAPR} = 5.70\text{ dB}$
2. **Model & Rule Bias**: Both the ONNX RadioML 2018 model and the DSP classification rules interpret any continuous un-strobed IQ signal with $\text{PAPR} > 5.40\text{ dB}$ as **256QAM**.

### C. Why Text Demodulation Fails for non-BPSK Synthetic Signals
* [sg.py](file:///e:/SIH%2726%20-%20Restart/Test-Data/sg.py) generates [hello_qpsk.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_qpsk.iq), [hello_8psk.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_8psk.iq), [hello_16qam.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_16qam.iq), [hello_64qam.iq](file:///e:/SIH%2726%20-%20Restart/Test-Data/hello_64qam.iq), and `hello_256qam.iq` by calling `np.random.choice()` over constellation point grids.
* **No ASCII text is encoded in these signals.** Demodulating these pseudo-random symbols packages random bit combinations into bytes, producing unprintable ASCII characters.
